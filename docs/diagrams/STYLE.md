# Diagram style and provenance

Lytronaut schematics use the Diagram Design v2.6 editorial system from
<https://github.com/cathrynlavery/diagram-design>, pinned for this documentation
refresh at upstream commit `550fd66edff058bc73056c3416b76d69cfe865ba`
(2026-10-16). The project explicitly selected the upstream default profile:
paper `#f5f5f5`, ink `#2d3142`, accent `#bf4520`, muted `#4f5d75`, soft
`#5a6580`, and link `#2e5aa8`.

Headings use Instrument Serif, human-readable node names use Geist, and technical
labels use Geist Mono. Local/system serif, sans-serif, and monospace families are
the disclosed offline fallbacks. Nodes use 6 px radii, badges 2 px, no shadows,
a 4 px structural grid, and orthogonal connectors with 8 px elbows. Each HTML
source is self-contained apart from the permitted Google Fonts stylesheet and
has a standalone SVG companion for repository rendering.

The diagrams are original Lytronaut content and geometry created from the
project's implemented contracts; upstream template markup or source code was not
copied. This file records style provenance rather than adding a runtime dependency.
